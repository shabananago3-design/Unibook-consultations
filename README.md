
# UniBook Consultations

## Project Description
UniBook Consultations is a responsive web application designed to solve a real problem at our university: the difficulty students face when trying to find and book office hours with lecturers. 

## Intended Users
*   **Students:** To easily find staff, view office locations, and book available time slots.
*   **Lecturers:** To manage their availability and avoid double-bookings.

## Features
*   **Responsive Design:** Built with Flexbox and CSS Grid (via Bootstrap) to work on mobile, tablet, and desktop.
*   **Search & Filter:** Students can search for lecturers by name or filter by department.
*   **Form Validation:** The booking form prevents empty submissions and double-booking of time slots.
*   **Feedback States:** Displays clear green success messages and red error messages.
*   **8+ Sample Records:** Includes a dynamic dataset of 8 lecturer profiles.

## Limitations
*   This is a front-end prototype. It uses browser-side processing and sample data. It does not connect to a database or university authentication system.
*   Bookings are not saved permanently; they reset if the page is refreshed.
